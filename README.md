# Hiba Hashmi — Portfolio

A plain HTML/CSS/JS rebuild of my Framer portfolio, hosted on GitHub Pages.

## Structure
- `index.html`: home page (intro, case study cards, contact)
- `css/styles.css`: all styles. Colors and fonts are set as variables at the top.
- `js/main.js`: mobile menu and fade-in on scroll

## Phases
1. Home page (current). Card images still load from Framer, and case study and About links still go to the Framer site.
2. Case studies, password protected
3. About page
4. Move all images into this repo
